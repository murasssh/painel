Política de privacidade — Painel

O Painel é uma ferramenta pessoal que envia vídeos para o canal do YouTube do próprio dono.

Dados acessados

Com a sua autorização, o Painel usa a YouTube Data API apenas para enviar vídeos e definir título, descrição e privacidade deles no seu canal.

Armazenamento

O token de acesso fica salvo só no computador do dono da ferramenta. Nenhum dado é enviado a servidores de terceiros, vendido ou compartilhado.

Revogar acesso

Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
